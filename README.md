# 🧠 Hache's Quizz

**Hache's Quizz** es una aplicación de preguntas de **verdadero o falso** para Android, desarrollada con **Kotlin y Jetpack Compose** 

## 🎮 Funcionalidades

- Dos categorías de preguntas: **modo clásico** y **modo niñ@s**.
- Tres formas de jugar: **sin tiempo**, **fácil** (15 segundos) y **difícil** (8 segundos).
- Navegación entre preguntas: **anterior**, **siguiente** y **aleatoria**.
- Indicación visual de respuestas correctas e incorrectas.
- **Estadísticas** de aciertos, fallos, porcentajes y clics.
- Posibilidad de **añadir preguntas** y guardarlas en un fichero de texto local.
- **Modo claro y oscuro**, con preferencia guardada.

## 🛠️ Tecnologías utilizadas

- Kotlin
- Jetpack Compose y Material 3
- Android Studio
- `ArrayList`, almacenamiento interno de archivos y `SharedPreferences`
- `CountDownTimer` para el modo contrarreloj

## ▶️ Cómo ejecutarlo

1. Clona o descarga este repositorio.
2. Ábrelo en **Android Studio**.
3. Deja que Gradle sincronice el proyecto.
4. Ejecútalo en un emulador o dispositivo Android compatible.
